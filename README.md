# Saylani Welfare Website Clone

A recreation of the Saylani Welfare International Trust website built using **HTML5 and CSS3** as part of my SMIT learning journey.

## 🌐 Live Demo

[View Live Website](https://saylaniwelfareclone1.netlify.app/)

## 📌 About the Project

This project is inspired by the official Saylani Welfare website. I recreated its layout and design to practice my frontend development skills and improve my understanding of HTML and CSS.

I completed this project in approximately **2 days**.

## ✨ Features

- Header with navigation menu
- Hero section with heading, image, and call-to-action buttons
- Donation and welfare service cards
- Newsletter subscription section
- Footer with social media icons and contact information
- Hover effects and styled buttons
- Custom typography using Google Fonts
- Icons using Font Awesome

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## 📚 What I Learned

- Structuring a multi-section website using HTML5
- Styling layouts using CSS3
- Using Flexbox and CSS Grid
- Creating hover effects, gradients, and shadows
- Working with images, icons, and typography
- Building a website inspired by a real-world design

## 🚀 Future Improvements

- Make the website fully responsive using CSS media queries
- Improve mobile and tablet layouts
- Add functionality to interactive elements
